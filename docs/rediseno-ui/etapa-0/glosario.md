# Etapa 0.3 — Glosario y voz de alphataco (APROBADO por el usuario el 2026-10-10)

Regla: ningún término visible igual a GH, salvo los **términos del rubro** que el usuario final usa fuera del
sistema (se mantienen y se dice por qué). Un objeto = un nombre en todo el sistema.

## 1. Voz

- **Voseo** en todo (hoy hay mezcla: "No tenés permisos…" / "No tienes permisos…"). "Ingresá", "Elegí", "Revisá".
- Botones con **verbo + objeto** cuando el verbo aporta ("Subir documento"), y **objeto + "nuevo/a"** para las altas:
  "Persona nueva", "Unidad nueva", "Cliente nuevo" (GH: "Agregar empleado", "Registrar Cliente", "Crear X").
- Mensajes de éxito con números ("Se asignaron 3 personas a Vista Oil"), nunca genéricos.
- Tildes completas (hoy: "Iniciar Sesion", "compañia", "Proximos vencimientos").
- Sentence case en títulos y botones ("Unidades observadas", no "Equipos Con Desvíos").
